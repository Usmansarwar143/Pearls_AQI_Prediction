How to Read SHAP Charts

Positive SHAP Value

This feature increases the predicted AQI — pushes toward higher pollution.

Negative SHAP Value

This feature decreases the predicted AQI — pushes toward cleaner air.

Base Value

The model's average prediction across all training data. SHAP values add/subtract from this base.

Global Importance

Mean absolute SHAP value across the entire dataset. Higher = more influential feature overall.

System Architecture & Pipeline Flow

Three independent pipelines connected through a central Feature Store and Model Registry.

Feature Pipeline (Hourly)

Fetches raw pollution data from OpenWeather and weather from Open-Meteo, computes temporal features (hour, day_of_week, month), derived features (aqi_change_rate, aqi_rolling_24h), and pushes to Hopsworks Feature Store.

APIs
>
Feature Engine
>
Feature Store

Training Pipeline (Daily)

Pulls historical features + targets from Hopsworks, fits StandardScaler, trains RandomForest & Ridge Regression, selects best by R², and uploads winner to Model Registry with SHAP metadata.

Feature Store
>
Train & Evaluate
>
Model Registry

Inference Pipeline (Hourly)

Downloads latest model + scaler from registry, fetches latest features, generates predictions, computes SHAP values, queries HuggingFace LLM, and writes enriched predictions.json for the dashboard.
