📖 How to Read SHAP Charts

🔴
Positive SHAP Value (Red)

This feature increases the predicted AQI. Larger bars mean stronger push toward higher pollution.

🔵
Negative SHAP Value (Blue)

This feature decreases the predicted AQI. It contributes toward cleaner air predictions.

📊
Base Value

The model's average prediction across all training data. Individual feature SHAP values add to or subtract from this base to produce the final prediction.

🌍
Global Importance

Mean absolute SHAP value for each feature across the entire dataset. Higher = more influential feature overall.
